# مرجع مادر آموزش PHP — AS Academy

> این فایل منبع حقیقت محتوای دوره است. Course Package و اپلیکیشن باید از این ساختار پیروی کنند و هیچ Release آموزشی قبل از پوشش کامل این مرجع نهایی محسوب نمی‌شود.

- 180 درس مستقل
- تمرین متصل به درس‌ها
- آزمون متصل به فصل‌ها
- پروژه متصل به مهارت‌ها
- پروژه نهایی Production

## تمرین‌ها
حداقل برای هر 2 درس یک تمرین مستقل و برای مباحث کلیدی یک تمرین اختصاصی لازم است. انواع تمرین: خواندن و تحلیل کد، پیش‌بینی خروجی، نوشتن کد، تکمیل کد، رفع خطا، Refactor و Build Feature. هدف نهایی حداقل 150 تمرین واقعی است.

## قرارداد کیفیت هر درس
هر درس باید شامل هدف، پیش‌نیاز، توضیح مفهومی، Syntax، حداقل دو مثال، تشریح مرحله‌ای کد، خروجی، نکات مهم، خطاهای رایج، نکته امنیتی/Performance در صورت ارتباط، تمرین، پاسخ یا راهنمای حل، و اتصال به مهارت/پروژه مرتبط باشد.

## Release Gate آموزشی
Release نهایی دوره تنها زمانی مجاز است که همه درس‌های این مرجع در Course Package وجود داشته باشند، ارجاعات تمرین/آزمون/پروژه معتبر باشند، عملکرد Progress و Bookmark در Runtime تست شده باشد و هیچ گزینه نمایشی بدون عملکرد باقی نمانده باشد.
