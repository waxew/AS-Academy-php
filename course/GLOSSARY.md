# واژه‌نامه PHP

- API: رابط برنامه‌نویسی برای ارتباط نرم‌افزارها.
- Authentication: احراز هویت کاربر.
- Authorization: بررسی مجوز دسترسی.
- Composer: مدیر وابستگی استاندارد اکوسیستم PHP.
- Cookie: داده کوچک ذخیره‌شده در Client.
- CRUD: Create, Read, Update, Delete.
- CSRF: حمله جعل درخواست از طرف کاربر احرازشده.
- DTO: شیء انتقال داده بین لایه‌ها.
- MVC: Model, View, Controller.
- Namespace: فضای نام برای جلوگیری از تداخل نام‌ها.
- ORM: نگاشت داده‌های رابطه‌ای به Objectها.
- PDO: API استاندارد PHP برای دسترسی به دیتابیس‌های مختلف.
- PSR: مجموعه توصیه‌ها و استانداردهای PHP-FIG.
- Queue: صف پردازش کارهای پس‌زمینه.
- RBAC: کنترل دسترسی مبتنی بر نقش.
- Redis: data store سریع در حافظه برای cache/queue و موارد دیگر.
- REST: سبک معماری رایج برای APIهای HTTP.
- Session: وضعیت کاربر که معمولاً سمت سرور نگهداری می‌شود.
- SQL Injection: تزریق دستورات SQL از ورودی کنترل‌نشده.
- XSS: تزریق محتوای اجرایی ناخواسته به صفحه وب.
