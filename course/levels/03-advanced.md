# سطح 03 — PHP پیشرفته

## هدف سطح
حرکت از scriptهای کوچک به codebase ساخت‌یافته، امن و قابل تست.

## درس 19 — OOP
Class، Object، Constructor، Visibility، Encapsulation، Composition، Inheritance، Interface، Trait و Polymorphism.

## درس 20 — PHP مدرن
Strict types، typed properties، union/nullable types، readonly، enum، attributes، closure، generator و iterator.

## درس 21 — Composer و PSR
Dependency management، `composer.json`، Semantic Versioning، Namespace و PSR-4 autoloading.

## درس 22 — Exception و Logging
Exception باید در boundary مناسب گرفته شود. خطای داخلی log می‌شود و پاسخ امن به Client برمی‌گردد.

## درس 23 — MVC
جریان نمونه:
`Request -> Router -> Controller -> Service -> Repository -> Database -> Response`
View فقط مسئول presentation است.

## درس 24 — SOLID
SRP/OCP/LSP/ISP/DIP با refactoring مثال‌های واقعی آموزش داده می‌شوند.

## درس 25 — Patternها
Factory، Strategy، Adapter، Observer، Repository و Dependency Injection. Pattern زمانی استفاده می‌شود که مسئله واقعی را ساده‌تر کند.

## درس 26 — امنیت وب
SQL Injection، XSS، CSRF، Session fixation/hijacking، password hashing، upload attacks، brute force و secret management.

## درس 27 — Authentication و Authorization
Register/Login/Logout، password reset concept، Role/Permission و policy-based authorization.

## درس 28 — REST API
Resource، URI، Method، Status Code، JSON، validation، pagination، filtering، sorting و error envelope.

## درس 29 — API Security
Token lifecycle، rate limiting، CORS، authorization، idempotency و audit logging.

## پروژه سطح
REST API فروشگاه کوچک با user/product/order، معماری لایه‌ای، authentication، authorization و test plan.

## معیار تسلط
دانشجو باید بتواند مرزهای معماری را توضیح دهد، vulnerabilityهای رایج را شناسایی کند و API منسجم طراحی کند.
