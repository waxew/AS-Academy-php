## قرارداد کیفیت هر درس
هدف و پیش‌نیاز؛ توضیح مفهومی؛ Syntax؛ حداقل دو مثال؛ اجرای نمونه و Output؛ تشریح مرحله‌ای؛ نکات مهم؛ خطاهای رایج؛ Security/Performance در صورت ارتباط؛ تمرین فوری؛ Hint/Solution؛ اتصال به پروژه؛ منابع تکمیلی. درس‌های مناسب باید تجربه تعاملی مشابه Code → Run → Output → Exercise داشته باشند.

## Release Gate آموزشی
Release نهایی فقط زمانی مجاز است که Course Package تمام 490 درس را پوشش دهد، هیچ Lesson placeholder نباشد، تمرین/Quiz/Projectها معتبر باشند، Code/Output قابل استفاده باشد، Progress و Bookmark/Favorite در Runtime واقعاً تست و پایدار باشند و هیچ گزینه نمایشی بدون عملکرد باقی نماند.
