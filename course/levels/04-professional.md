# سطح 04 — تخصصی و Production

## هدف سطح
ساخت، تست، بهینه‌سازی و انتشار Backend واقعی PHP/Laravel.

## درس 30 — Laravel Foundation
Composer installation، project structure، config، environment، Artisan، routing، controller و Blade.

## درس 31 — Eloquent و Database
Migration، model، relationship، query builder، seeder، factory، transaction و جلوگیری از N+1.

## درس 32 — Laravel Application Layer
Form Request، Service، Policy، Resource، Event/Listener، Notification و Storage.

## درس 33 — Laravel API/Auth
API Resource، token authentication با راهکار رسمی مناسب پروژه، authorization و rate limiting.

## درس 34 — Testing
Unit، Integration، Feature و API test. Arrange/Act/Assert، fixture/factory، mock و coverage.

## درس 35 — Cache و Redis
Cache-aside، TTL، invalidation، Redis و انتخاب داده مناسب برای cache.

## درس 36 — Queue
Job، worker، retry، backoff، failed job و idempotency. عملیات کند از request path جدا می‌شوند.

## درس 37 — Performance
OPcache، index، query plan، N+1، eager loading، pagination، profiling و benchmark.

## درس 38 — Docker
Container برای PHP، Nginx، MySQL و Redis؛ volume، network و environment separation.

## درس 39 — Git و CI
Branch/PR/review، lint، static analysis، test و build در CI.

## درس 40 — Deployment
Linux، SSH، Nginx/Apache، DNS، TLS، permission، environment، migration، queue worker و scheduler.

## درس 41 — Operations
Structured logging، monitoring، health check، backup، restore test، incident basics و rollback.

## درس 42 — Backend موبایل
API contract مناسب Android/iOS، access/refresh token، pagination، upload، versioning و error model.

## پروژه نهایی
سامانه تجاری PHP/Laravel با Auth/RBAC، Product/Inventory، Cart/Order، Payment abstraction، Invoice، Notification، API، Admin، Audit، Queue، Redis، Tests، Docker، CI/CD و runbook انتشار.

## معیار تسلط
پروژه باید قابل راه‌اندازی تکرارپذیر، دارای تست، فاقد Secret در Git، دارای migration/backup/rollback و دارای مستند معماری باشد.
