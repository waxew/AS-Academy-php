# پروژه‌های عملی دوره PHP

## P01 Calculator
ماشین‌حساب با توابع، validation و مدیریت تقسیم بر صفر.

## P02 Contact Form
فرم تماس با validation، sanitization و نمایش پیام خطا.

## P03 Todo
CRUD وظایف با فایل و سپس نسخه دیتابیسی.

## P04 Phone Book
مخاطبین، جستجو، مرتب‌سازی و pagination.

## P05 Authentication
Register/Login/Logout، password_hash، session و CSRF.

## P06 User Manager
CRUD کاربران + Role/Permission + Audit پایه.

## P07 Blog
Post، Category، Comment، Admin، slug و pagination.

## P08 File Manager
Upload/Download/Delete با authorization و محدودیت نوع/حجم.

## P09 Invoice
Customer، Product، Invoice، InvoiceItem، محاسبه جمع و گزارش.

## P10 REST API
API نسخه‌بندی‌شده برای users/products/orders با JSON و auth.

## P11 Appointment
کاربر، سرویس، زمان‌بندی، رزرو، لغو و notification job.

## P12 E-commerce
Category، Product، Inventory، Cart، Order، Discount، Payment abstraction و Admin.

## P13 Mobile Backend
Backend مناسب Kotlin/Android با token، refresh، pagination، upload و error contract.

## P14 Laravel Production
بازسازی قابلیت‌های اصلی پروژه فروشگاه با Laravel، Eloquent، Queue، Cache، Policies و Tests.

## P15 Master Project
سامانه تجاری Production-ready شامل:
- Authentication و RBAC
- Catalog و Inventory
- Cart و Order
- Payment abstraction
- Invoice
- Notification
- REST API
- Admin
- Audit log
- Redis/Cache
- Queue
- Tests
- Docker
- CI/CD
- Backup/Restore plan
- Deployment/rollback runbook

## Definition of Done
هر پروژه باید README، راه‌اندازی، schema دیتابیس، `.env.example` بدون Secret، validation، مدیریت خطا، نکات امنیتی، تست‌های لازم و توضیح معماری داشته باشد.
