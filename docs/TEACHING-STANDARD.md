# استاندارد تدریس AS Academy PHP

این سند قرارداد اجرایی تولید تمام درس‌های PHP است. الگوی ارائه از روش مرحله‌ای و مثال‌محور W3Schools الهام می‌گیرد، اما محتوا، مثال‌ها، تمرین‌ها و پروژه‌ها اختصاصی AS Academy هستند و برای Backend حرفه‌ای عمیق‌تر می‌شوند.

## قالب اجباری هر درس
1. عنوان روشن و شماره درس
2. «در این درس چه یاد می‌گیریم؟» در 2 تا 5 هدف کوتاه
3. پیش‌نیاز در صورت نیاز
4. توضیح ساده مفهوم قبل از اصطلاحات پیچیده
5. Syntax مستقل و قابل مشاهده
6. Example 1: ساده‌ترین نمونه قابل اجرا
7. Output نمونه
8. توضیح خط‌به‌خط/مرحله‌ای Example 1
9. Example 2: نمونه واقعی‌تر
10. Output و تحلیل Example 2
11. Try It Yourself: تغییر کوچک در کد توسط دانشجو
12. نکات مهم
13. خطاهای رایج و علت آنها
14. Security Note در موضوعات مرتبط
15. Performance Note در موضوعات مرتبط
16. Exercise متصل به lessonId
17. Hint
18. Solution/Expected Output
19. Quiz کوتاه 2 تا 5 سؤال در مباحث مناسب
20. Previous / Next برای مسیر خطی یادگیری

## قواعد نوشتن
- هر درس یک موضوع اصلی دارد؛ چند مبحث بزرگ در یک درس فشرده نمی‌شوند.
- آموزش از مثال ساده به مثال واقعی حرکت می‌کند.
- اصطلاح انگلیسی کنار معادل فارسی حفظ می‌شود.
- کد باید مستقل، قابل کپی و تا حد امکان قابل اجرا باشد.
- خروجی کد باید نمایش داده شود، نه اینکه فقط کد ارائه شود.
- توضیح کد برای مبتدی نباید دانش قبلی فرض کند.
- مثال‌های Production باید محدودیت، خطا و حالت شکست را نیز توضیح دهند.
- امنیت از فصل Security شروع نمی‌شود؛ از اولین Form، Database، Session و Upload در همان درس آموزش داده می‌شود.

## الگوی فصل
هر فصل شامل: Introduction، مجموعه درس‌های مرحله‌ای، Examples، Exercises، Quiz فصل، Mini Project و Summary است.

## تجربه داخل برنامه
Lesson Screen باید بخش‌های Syntax، Code، Output، Note/Tip/Warning، Try It Yourself و Exercise را واضح نمایش دهد. دکمه‌های مطالعه‌شده و Favorite باید state واقعی و persistent داشته باشند. Previous/Next باید بین درس‌ها کار کند. Progress از داده ذخیره‌شده محاسبه شود.

## معیار پذیرش درس
درس ناقص است اگر فقط عنوان/چند پاراگراف داشته باشد، Syntax یا مثال نداشته باشد، مثال بدون توضیح باشد، تمرین به درس متصل نباشد، یا محتوای آن صرفاً placeholder باشد.

## معیار پذیرش فصل
فصل فقط وقتی Complete است که تمام درس‌های Master Curriculum مربوط به آن، Quiz، Exerciseها و Mini Project موردنیاز موجود و معتبر باشند.
