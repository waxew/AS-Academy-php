# سیستم ارزیابی دوره PHP

کاربر فقط با خواندن متن دوره را کامل نمی‌کند.

- هر سطح: درس + تمرین + Quiz + پروژه سطح
- مبانی: حداقل 70٪
- مقدماتی: حداقل 75٪
- پیشرفته: حداقل 75٪
- تخصصی و آزمون نهایی: حداقل 80٪
- Capstone: اجباری

## معیار پروژه نهایی
صحت عملکرد، ساختار معماری، امنیت، تست، مدیریت خطا، کیفیت دیتابیس، API contract، performance، قابلیت deploy، monitoring و recovery بررسی می‌شوند.
