# مسیر تکمیل دوره داخل اپ

## مبانی
درس‌های شروع و هسته زبان → تمرین‌های متغیر/تابع → Quiz مبانی → پروژه محاسبه‌گر خرید.

## مقدماتی
HTTP/Form → Session/Auth → Upload → SQL/PDO → CRUD → Quiz دیتابیس → پروژه مدیریت مخاطبین.

## پیشرفته
OOP → Composer/PSR → Exception → PHP مدرن → MVC → SOLID → Security → REST API → Quiz معماری/امنیت → پروژه API فروشگاه.

## تخصصی
Laravel → Eloquent → Validation/Policy/API Resource → Auth → Event/Notification/Storage → Testing → Redis/Queue → Performance → Docker → CI/CD/Operations → Mobile Backend → آزمون‌های Laravel/Production → پروژه نهایی.

## Definition of Complete
- مشاهده و تکمیل درس‌ها
- حداقل 70٪ آزمون مبانی و دیتابیس
- حداقل 75٪ آزمون پیشرفته
- حداقل 80٪ آزمون Laravel و Production
- تکمیل پروژه هر سطح
- تکمیل Capstone و مستند معماری/استقرار
