# تمرین‌ها و آزمون‌های PHP

## مبانی
1. برنامه‌ای بنویسید که نام و سن را در متغیر ذخیره و چاپ کند.
2. عددی دریافت و زوج یا فرد بودن آن را مشخص کنید.
3. مجموع اعداد 1 تا 100 را با حلقه محاسبه کنید.
4. آرایه‌ای از نمرات بسازید و میانگین را محاسبه کنید.
5. تابعی برای محاسبه قیمت نهایی با درصد تخفیف بنویسید.

## مقدماتی
6. فرم ثبت‌نام با validation سمت سرور بسازید.
7. Session ورود کاربر را پیاده‌سازی کنید.
8. Upload تصویر را با محدودیت MIME و حجم پیاده‌سازی کنید.
9. CRUD کاربران را با PDO و prepared statement بسازید.
10. جستجو و pagination به CRUD اضافه کنید.

## پیشرفته
11. سیستم کاربران را با Class و Repository بازنویسی کنید.
12. Autoloading مبتنی بر Composer/PSR-4 اضافه کنید.
13. Router و MVC کوچک خودتان را بسازید.
14. CSRF protection به فرم‌ها اضافه کنید.
15. REST API برای users/products طراحی کنید.
16. Role و Permission برای admin/editor/user پیاده‌سازی کنید.

## تخصصی
17. همان API را با Laravel پیاده‌سازی کنید.
18. Feature test برای Login و CRUD بنویسید.
19. Queue ارسال ایمیل سفارش را بسازید.
20. Cache و Redis را برای endpoint پرترافیک اضافه کنید.
21. پروژه را Dockerize کنید.
22. CI برای lint/test بسازید.
23. پروژه را روی محیط production آزمایشی deploy و rollback را مستند کنید.

## نمونه سوال Quiz
- تفاوت `==` و `===` چیست؟ پاسخ: `===` علاوه بر مقدار، نوع را نیز مقایسه می‌کند.
- چرا Prepared Statement مهم است؟ پاسخ: داده را از ساختار SQL جدا و ریسک SQL Injection را کاهش می‌دهد.
- تفاوت Authentication و Authorization چیست؟ پاسخ: اولی هویت را مشخص می‌کند؛ دومی مجوز انجام عملیات را.
- چرا Secret نباید در Git ذخیره شود؟ پاسخ: تاریخچه Git می‌تواند آن را برای مدت طولانی افشا کند.
- چه زمانی Queue مناسب است؟ پاسخ: برای عملیات کند یا قابل‌تعویق که نباید پاسخ HTTP را مسدود کنند.
